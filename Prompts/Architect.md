# Architect Prompts

## Diseño de Sistemas

```
Actúa como un Arquitecto de Software Senior. Diseña la arquitectura para [DESCRIBIR SISTEMA].

Considera:
- Requisitos funcionales y no funcionales
- Escalabilidad y disponibilidad
- Patrones de diseño apropiados
- Stack tecnológico recomendado

Proporciona:
1. Visión general de la arquitectura
2. Componentes principales
3. Decisiones técnicas clave
4. Riesgos y mitigaciones
```

## Code Review

```
Revisa este código como Arquitecto de Software:
[CÓDIGO]

Evalúa:
- Adherencia a SOLID
- Patrones de diseño
- Performance y escalabilidad
- Seguridad
- Mantenibilidad
```

## Decisiones Técnicas

```
Necesito decidir entre [OPCIÓN A] vs [OPCIÓN B] para [CONTEXTO].

Analiza pros/contras y recomienda la mejor alternativa.
```
