# Pull Request Checklist

## Arquitectura

- [ ] Respeta la arquitectura hexagonal.
- [ ] No rompe dependencias.
- [ ] No introduce acoplamiento.

## Código

- [ ] Nombres claros.
- [ ] Métodos pequeños.
- [ ] Responsabilidad única.
- [ ] Sin código duplicado.

## Dominio

- [ ] Reglas de negocio encapsuladas.
- [ ] Value Objects inmutables.
- [ ] No Primitive Obsession.

## Tests

- [ ] Casos felices.
- [ ] Casos límite.
- [ ] Casos de error.

## Documentación

- [ ] KnowledgeBase actualizada.
